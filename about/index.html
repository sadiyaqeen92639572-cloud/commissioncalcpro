This site provides free calculators for real estate commission, net proceeds, and closing costs, built to reflect the current rules following the August 2024 NAR settlement.

Sourcing methodology

We don't publish a single "average commission" figure. NAR does not release official per-state averages, so every number on this site traces to a named referral-company survey with its sample size and survey date shown — see realtor fees by state for the full sourced ranges.
